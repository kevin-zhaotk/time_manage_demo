# 日历转换App - 高保真原型设计

一个专业的公历日期和农历日期互相转换的移动应用原型，采用iPhone 13 Pro Max设计规范，提供现代化的用户界面和流畅的交互体验。

## 🎯 项目概览

### 核心功能
- 📅 公历日期转农历日期
- 🌙 农历日期转公历日期
- 📊 今日日期信息展示
- 🔍 历史查询记录管理
- ⭐ 重要日期收藏功能
- 🌿 节气和传统节日信息
- ⚙️ 个性化设置选项

### 设计特色
- 🎨 遵循iOS设计规范
- 📱 iPhone 13 Pro Max尺寸适配（428×926px）
- 🎭 无边框圆角设计
- 🌈 现代化渐变和配色方案
- ✨ 流畅的动画效果
- 🔄 响应式交互设计

## 📱 页面详情

### 1. 主页 (home.html)
- **今日信息卡片**：显示当前公历和农历日期
- **快速功能入口**：日期转换、查询记录
- **节气日历**：展示即将到来的节气
- **传统节日**：重要节日倒计时

### 2. 日期转换 (converter.html)
- **模式切换**：公历转农历 / 农历转公历
- **日期选择器**：年月日选择组件
- **转换结果**：详细的转换信息展示
- **附加信息**：节气、星宿、五行等

### 3. 历史记录 (history.html)
- **收藏夹**：重要日期收藏管理
- **最近查询**：按时间分组的查询记录
- **搜索功能**：快速查找历史记录
- **批量操作**：删除、收藏等功能

### 4. 设置页面 (settings.html)
- **用户信息**：使用统计和个人资料
- **显示设置**：主题、字体、语言配置
- **功能设置**：自动保存、通知、同步
- **其他选项**：反馈、关于、隐私政策

## 🎨 设计规范

- **主色调**：#007AFF (iOS系统蓝)

- **渐变色**：多种场景化渐变配色

- **正文**：17px/400 (body-text)

## 🚀 使用说明

### 本地运行
1. 下载所有文件到本地目录
2. 使用现代浏览器打开任意HTML文件
3. 推荐使用Chrome或Safari获得最佳体验

### 开发建议
1. **响应式测试**：使用浏览器开发者工具测试不同屏幕尺寸
